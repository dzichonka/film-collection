About the project

This project was created as part of learning modern Angular 21. There is no RxJS — only clean, modern Signals.

It demonstrates core Angular concepts such as:

  • Standalone Components
  • Routing and lazy loading
  • New template control flow
  • Signals-based reactivity
  • Pipes and directives
  • Strict TypeScript mode
  • No RxJS at all

Course
